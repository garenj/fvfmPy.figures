# fvfmPy and fvfmR
## Scripts to reproduce data-based figures and tables from the associated manuscript
### Josef Garen, Pieter Arnold, and Kristine Crous, 2026

This repo houses data and scripts to reproduce the data-based figures and tables from the manuscript associated with the fvfmPy project.

All figures and tables can be produced by running the script [R/main.R](https://github.com/garenj/fvfmPy.figures/blob/main/R/main.R).

The markdown file [R/TLS_thermal_analysis_example.Rmd](https://github.com/garenj/fvfmPy.figures/blob/main/R/TLS_thermal_analysis_example.Rmd) includes a complete example workflow for thermal load sensitivity analysis integrated with fvfmPy.

The file [USER_GUIDE.pdf](https://github.com/garenj/fvfmPy.figures/blob/main/USER_GUIDE.pdf) contains detailed instructions on the use of the fvfmPy and fvfmR programs.
